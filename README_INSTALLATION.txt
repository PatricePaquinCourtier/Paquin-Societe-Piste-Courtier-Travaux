PISTE — module site avec galerie Avant / Après

Contenu :
- index.html : aperçu autonome du site
- views/website_page.xml : template de page Odoo
- static/src/css et static/src/js : styles et interactions
- static/src/img/portfolio : 84 images Avant / Après (42 comparaisons)
- CONTROLE_AVANT_APRES.md : audit des PDF, doublons et regroupements

Déploiement Odoo :
1. Copier le dossier courtier_travaux_odoo_ready dans le répertoire des addons personnalisés.
2. Mettre à jour la liste des applications.
3. Installer ou mettre à niveau le module « Courtier Travaux Website ».
